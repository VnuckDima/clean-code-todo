# Отчёт по ревью кода TODO-приложения

## 1. Мёртвый код

Проблем не выявлено. В предыдущих коммитах уже удалена пустая функция `ajaxRequest` и её регистрация на клик кнопки «Add». Все оставшиеся функции и обработчики используются.

## 2. Дублирование (обработчиков и логики)

- **Место:** `app.js`, строки 112–118 (два цикла `for`).
- **Проблема:** Два цикла практически идентичны: оба перебирают дочерние элементы списка задач и вызывают `bindTaskEvents`, отличаются только целевым списком (`incompleteTaskHolder`/`completedTasksHolder`) и следующим обработчиком (`taskCompleted`/`taskIncomplete`).
- **Условие проявления:** При необходимости изменить порядок или способ привязки событий нужно править оба цикла, иначе возможна несогласованность.
- **Способ проверить исправление:** Объединить циклы в один (передавая holder и handler) или вынести в отдельную функцию; после этого при клике на чекбокс задачи по-прежнему перемещаются между списками, а при перезагрузке страницы существующие задачи корректно принимают чекбокс/редактирование/удаление.

## 3. Имена переменных и функций

- **Место:** `app.js`, функции `taskCompleted` (стр. 92) и `taskIncomplete` (стр. 96).
- **Проблема:** Имена описывают состояние задачи («завершена / не завершена»), а не действие, которое выполняет функция (перемещение задачи между списками «Todo» и «Completed»). В контексте чекбокса они понятны, но не отражают суть перемещения.
- **Условие проявления:** Читателю требуется дополнительная секунда, чтобы понять, что функции не просто помечают задачу, а переносят её в другой список и перевязывают события.
- **Способ проверить исправление:** Переименовать в `moveToCompleted` / `moveToIncomplete` (или оставить с обоснованием). Поведение не меняется — чекбокс по-прежнему переносит задачу между списками.

- **Место:** `app.js`, строка 2, получение `addButton` через `document.getElementsByTagName('button')[0]`.
- **Проблема:** Получение кнопки по индексу среди всех кнопок документа — хрупко: если в HTML появится другая кнопка выше «Add», приложение сломается (начнёт обрабатывать не ту кнопку).
- **Условие проявления:** Любое изменение разметки, добавляющее кнопку перед «Add», приведёт к неверной работе.
- **Способ проверить исправление:** Использовать `document.getElementById` (добавить `id` кнопке в HTML) или `querySelector` с более точным селектором. Проверить, что при клике на «Add» добавляется задача.
